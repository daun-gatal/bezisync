# public

## Overview
Static files Vite copies unchanged to the root of the built site, served by nginx next to the bundled app. They are fetched by URL (`/theme.js`, `/favicon.svg`, `/licenses.txt`) rather than imported.

## Interface
- `theme.js` — loaded by `index.html` before the app: reads `localStorage` `bz.theme` and, when it is `light` or `dark`, sets `data-theme` on `<html>` before the first paint.
- `favicon.svg` — the site icon (`index.html`).
- `licenses.txt` — the web UI's licence and third-party notice file, served at `/licenses.txt` (linked from the About dialog); generated by `make licenses` (`tools/cmd/licenses`).

## Invariants
- `theme.js` is a file, not an inline script, because the CSP in `nginx.conf.template` (`default-src 'self'`) forbids inline scripts; it must stay in step with `src/lib/theme.ts` (same `bz.theme` key and values) and swallow storage errors so a blocked store follows the system theme.
- Never edit `licenses.txt` by hand: `tools/licenses` writes it (`WebFile`) and `make licenses-check` fails when it is stale.

## Side Effects
- `theme.js` reads `localStorage` and sets the `data-theme` attribute on `document.documentElement`.

## Verification
- Run: No co-located tests; `make licenses-check` fails when `licenses.txt` is stale. `theme.js` has no automated test; its counterpart `src/lib/theme.ts` is covered by `cd frontend && bun run test src/lib`.
