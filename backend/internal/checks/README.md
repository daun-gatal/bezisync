# checks

## Overview
The preflight check model shared by connectors, deploy preflight, secret stores and project
policies: one `Check` per finding (stable code, plain message, technical detail, why, copyable
fix) collected into a `Report`. It also embeds the check reference (`catalog.json`) that
`bezisync check-docs` renders into `docs/reference/checks.md` and that the UI's "learn more"
links point at.

## Interface
- `[checks.go:Check]` — one result (`Code`, `Title`, `Status`, `Category`, `Message`, `Technical`, `Why`, `Fix`, `Blocking`, `Doc`); `Failed`.
- `[checks.go:Fix]` / `[checks.go:NewFix]` — copyable remediation (defaults kind `text`, who `DBA`).
- Status constants `[checks.go:Pass]`, `[checks.go:Warn]`, `[checks.go:Fail]`, `[checks.go:Skip]`; category constants `[checks.go:CatNetwork]` … `[checks.go:CatPolicy]`.
- `[checks.go:Report]` / `[checks.go:Summarize]` — builds the report: fills `Doc` links, `OK` = no failures, summary text ("N issues block deploy" / "Ready · N warnings" / "Ready"), duration and `CheckedAt`.
- `[checks.go:Run]` — collector for connector code (`Add`, `Passed`, `Blocked`).
- `[checks.go:DocURL]` / `[checks.go:DocsURL]` — reference link for a code (`_` → `-` anchor).
- `[checks.go:Catalog]` / `[checks.go:Entry]` / `[checks.go:LoadCatalog]` / `[checks.go:Render]` — the embedded reference and its Markdown rendering (used by the `check-docs` CLI command).

## Invariants
- `OK` is false whenever any check has status `fail`, whether or not it is `Blocking` (`[checks.go:Summarize]`); `[checks.go:Blocked]` uses the same rule.
- Every check code the backend emits (literal `Check{Code: "…"}` / `.Passed("…")`, plus `_blocked`/`_unreachable`/`_reachable` for each `NetworkCheck` base) must have an entry in `catalog.json`; `TestEveryEmittedCheckIsInTheCatalog` scans all non-test Go source under `internal/` (`[catalog_test.go:TestEveryEmittedCheckIsInTheCatalog]`).
- `docs/reference/checks.md` is generated by `[checks.go:Render]`; never edit it by hand. Entries render only under a section listed in `Sections`, sorted by code.
- An invalid `catalog.json` panics on load (`[checks.go:LoadCatalog]`).

## Side Effects
- None (reads only the embedded `catalog.json`).

## Verification
- Run: `make verify-quick GO_PKGS="./internal/checks/"`
