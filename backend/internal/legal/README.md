# legal

## Overview
Carries the licences BeziSync ships in its binary: BeziSync's own NOTICE and Apache License,
then every linked third-party Go module with its licence and notices. `licenses.txt` is
generated, not hand-edited. It is printed by `bezisync licenses` and served by the API.

## Interface
- `[legal.go:Licenses]` — the embedded text of `licenses.txt`.
- `licenses.txt` — generated by `make licenses` (`tools/cmd/licenses`).

## Invariants
- Never edit `licenses.txt` by hand; regenerate it with `make licenses` after a dependency change. `make licenses-check` (part of `make verify-quick`) fails when it is stale.
- BeziSync's own licence comes before third-party software (`[../cli/cli_test.go:TestLicensesPrintsOwnAndThirdPartyLicences]`).

## Side Effects
- None (the file is embedded at build time).

## Verification
- No co-located tests; covered by `make licenses-check` and `make verify-quick GO_PKGS="./internal/cli/"`.
